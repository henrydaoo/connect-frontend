# E-Commerce Platform

Full-stack e-commerce portfolio project built as a modular Spring Boot monolith and a Next.js App Router client.

## Stack

| Layer | Technology |
|---|---|
| Backend | Java 21, Spring Boot, Security/JWT, JPA, Flyway, PostgreSQL |
| Frontend | Next.js 14, React, TypeScript |
| Payments | VNPay sandbox, HMAC-SHA512, idempotent IPN |
| Operations | Docker, Actuator, MDC request IDs, Bucket4j |
